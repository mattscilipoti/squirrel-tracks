⚡ COMMON COMMANDS (Inside Container)
═══════════════════════════════════════════════════════════════════════════════

Terminal Commands:

  # Rails Backend
  cd backend
  bundle exec rails server              # Start API (http://localhost:3000)
  bundle exec rails console             # Interactive Ruby console
  bundle exec rails db:create           # Create SQLite databases
  bundle exec rails db:migrate          # Run migrations
  bundle exec rspec                     # Run tests

  # Web Frontend
  cd web-frontend
  python3 -m http.server 5000           # Start web (http://localhost:5000)

  # iOS
  cd ios-app
  pod install                           # Install CocoaPods

VS Code Tasks (Ctrl+Shift+P → "Tasks: Run Task"):

  • Rails: Start Server                 (starts on port 3000)
  • Rails: Database Create
  • Rails: Run Tests (RSpec)
  • Web: Start Dev Server               (starts on port 5000)
  • iOS: Pod Install
  • ETT: Full Setup                     (one-command setup)


🔍 DEBUGGING IN VS CODE
═══════════════════════════════════════════════════════════════════════════════

Debug Rails Server:
  1. Open backend/app/models/session.rb
  2. Click line number to set breakpoint (red dot)
  3. Press F5 (or Ctrl+Shift+D)
  4. Select "Rails server"
  5. Make HTTP request to trigger breakpoint
  6. Step through code in debugger

Debug Tests:
  1. Open backend/spec/models/session_spec.rb
  2. Set breakpoint
  3. Press F5 → select "RSpec - current file"
  4. Debugger pauses at breakpoint

🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"Docker daemon not running"
  → Start Docker Desktop, wait 30 sec, retry

"Permission denied" (Linux only)
  → sudo usermod -aG docker $USER
     (Then log out and back in)

"Address already in use (port 3000)"
  → kill $(lsof -t -i:3000)
     OR use: bundle exec rails server -p 3001

"Database is locked"
  → cd backend
     rm storage/development.sqlite3
     bundle exec rails db:create

"Gem not found"
  → cd backend
     rm Gemfile.lock
     bundle install

Check full troubleshooting in: .devcontainer/DEVCONTAINER.md
