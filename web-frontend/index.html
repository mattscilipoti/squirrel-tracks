Sync with GitHub

Your data is encrypted on this device and saved as small files in a private GitHub repository of yours. GitHub only ever sees scrambled data. Your devices sync even if they are never open at the same time.

You opened a sync link. Enter an access token for this device to finish; the repository and encryption key came with the link.

First-time setup (about 3 minutes)
  1. On github.com, create a new private repository (for example squirrel-tracks-data) and tick Add a README file.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Under Repository access choose Only select repositories and pick that repository.
  4. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed. Pick an expiry you are comfortable renewing.
  5. Copy the token (shown once) and paste it below with the repository name.

Repository:

This repository is public. Your data is encrypted, but a private repository is strongly recommended.

To add another device, open this link on it and enter a token there. The link carries the repository and encryption key, never the token. Keep it private.

Live pairing (advanced)

Pairing keeps this device and your others in sync, directly between them, with no account and no server holding your data. Both devices must have the app open at the same time to exchange changes.

Already have a link from another device? Just open it in this browser.

Open this link on your other device, or scan the code. Anyone who has it can read and change your data, so share it only with yourself.

No signaling server is set, so other devices cannot find this one. Add one under "Signaling server" below, then share the link (it carries the address).

Sync details

Signaling server

Devices find each other through a signaling server, which sees only encrypted connection set-up messages, never your data. There is no built-in one, because free public ones come and go. Run your own (npm run signaling, see the README) and enter its address here. Use ws://localhost:4444 to try it on this computer; from the https:// site other devices need a wss:// address. Set it before you share the link: the link carries it.
