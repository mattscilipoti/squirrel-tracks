Pairing keeps this device and your others in sync, directly between them, with no account and no server holding your data. Both devices must have the app open at the same time to exchange changes.

Sync details

Signaling server

Devices find each other through a signaling server, which sees only encrypted connection set-up messages, never your data. There is no built-in one, because free public ones come and go. Run your own (npx y-webrtc-signaling, see the README) and enter its address here. Use ws://localhost:4444 to try it on this computer; from the https:// site other devices need a wss:// address. Set it before you share the link: the link carries it.
